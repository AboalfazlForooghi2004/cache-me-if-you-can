# کَشَم کن اگه می‌تونی! — Cache Me If You Can

بازی آرکید-استراتژی مرورگری برای مسابقه‌ی **#GameOnEdge** ابر آروان.
ایران رو با نودهای لبه (Edge) پوشش بده، درخواست‌ها رو از کَش سرو کن و نذار هیچ‌کدوم به سرور مبدأِ دور برسند!

> **یک فایل. بدون بیلد. بدون اینترنت.** — `index.html` رو باز کن و بازی کن.

---

## اجرای بازی

- **ساده‌ترین راه:** روی `index.html` دابل‌کلیک کن (از `file://` هم کامل کار می‌کند).
- یا با هر سرور استاتیکی: `python3 -m http.server 8000` و بعد `http://localhost:8000/index.html`
- **موبایل:** فایل را روی گوشی باز کن؛ چیدمان mobile-first و RTL است.
- پیش‌نیاز: هر مرورگر مدرن با Canvas 2D (کروم/فایرفاکس/سafari/اِج). هیچ کتابخانه، فونت یا asset خارجی لود نمی‌شود.

## کنترل‌ها

| ورودی | عملکرد |
|---|---|
|ضربه / کلیک روی شهر | کاشت نود لبه (اگر اسلات باز باشد) |
| درگ نود به شهر دیگر | جابه‌جایی نود (کَشِ آن شهر **ریست** می‌شود!) |
| سوایپ روی ربات‌ها | نابودی موج DDoS قبل از رسیدن به نود |
| `Space` / `P` / کلیک روی ⏸ | توقف بازی |
| دکمه‌های پایین صفحه | اسلات‌های نود (قفل‌ها با پیشرفت باز می‌شوند) |

## مکانیک‌های اصلی

- **۱۵ شهر ایران** روی نقشه؛ هر درخواست از نزدیک‌ترین نودِ دارای کَشِ گرم سرو می‌شود، وگرنه به **سرور مبدأ** (خیلی دور!) می‌رود.
- **گرمای کَش (Warmth):** هر هیت، کَش را گرم‌تر و احتمال هیت بعدی را بیشتر می‌کند. جابه‌جایی نود = کَش سرد.
- **SLA / رضایت کاربران:** تایم‌اوت‌ها رضایت را پایین می‌آورند؛ به صفر برسد = باخت.
- **امتیاز × کمبو:** سرو سریع پشت‌سرهم، کمبو را بالا می‌برد؛ تایم‌اوت کمبو را می‌شکند.
- **رویدادها:** قطعی فیبر، جشنواره‌ی ترافیک، آپدیت کَش و موج بات‌ها — هر کدام استراتژی خودش را می‌طلبد.
- **چالش روزانه:** سیدِ قطعی بر اساس تاریخ تهران؛ هر روز یک نقشه‌ی یکسان برای همه.

## تست هدلس (هوک‌های `window.__game`)

بازی یک harness قطعی برای تست بدون مرورگر/بات مرورگری exposes می‌کند:

```js
window.__game.newRun(seed, 'endless', {tutorial:false});
window.__game.applyAction({type:'place', city:0});
window.__game.applyAction({type:'swipe', x1, y1, x2, y2});
window.__game.step(1/60);            // گام زمانی ثابت
window.__game.snapshot();            // وضعیت قابل‌سریال‌سازی
```

سه.policy مرجع (lazy / novice / greedy) در `02_DESIGN.md §14` تعریف شده‌اند؛
اهداف بالانس (§14): lazy ۲۵–۵۰ ثانیه، novice ۶۰–۱۱۰ ثانیه، greedy ≥ ۲۴۰ ثانیه (میانه‌ی بقا). اندازه‌گیری نهایی: lazy ≈ ۴۲s، novice ≈ ۱۰۴s، greedy ≈ ۳۱۳s.
خروجی آخرین اجرای بالانس‌سنجی در `DECISIONS.md` ثبت شده است.

## ساختار فایل

`index.html` تک‌فایل است (~۶۹KB، سقف مجاز ۱.۵MB) با بخش‌های مرتب:
`CONFIG · UTIL · DATA · STORAGE · SIM · INPUT · RENDER · AUDIO · UI · SHARE · DEMO · MAIN`

- **SIM:** timestep ثابت `DT=1/60` با accumulator (حداکثر ۵ گام per فریم) ⇒ قطعی و بدون اسپایرال مرگ.
- **RENDER:** لایه‌ی استاتیک (نقشه/پس‌زمینه) یک‌بار رسم و کش می‌شود؛ لایه‌ی پویا هر فریم. همه‌ی آرت پروسیجرال است.
- **AUDIO:** WebAudio با گام‌های موسیقی ایرانی (شور)؛ بدون هیچ فایل صوتی.
- **STORAGE:** `localStorage` با کلید `cmiyc.v1` داخل try/catch — بدون آن هم بازی کار می‌کند.
