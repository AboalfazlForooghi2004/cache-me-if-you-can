# کَشَم کن اگه می‌تونی! — Cache Me If You Can

بازی آرکید-استراتژی مرورگری برای مسابقه‌ی **#GameOnEdge** ابر آروان.
ایران رو با نودهای لبه (Edge) پوشش بده، درخواست‌ها رو از کَش سرو کن و نذار به سرور مبدأِ دور برسند!

> **یک فایل. بدون بیلد. بدون اینترنت.** — `index.html` رو باز کن و بازی کن. (۱۵۳KB، سقف مجاز ۶۰۰KB)

---

## اجرای بازی

- روی `index.html` دابل‌کلیک کن (از `file://` هم کامل کار می‌کند) یا با هر سرور استاتیکی سرو کن.
- موبایل: چیدمان mobile-first و RTL؛ در مرورگر دسکتاپ با عرض ≥۹۰۰px سایدبار راست فعال می‌شود و در گوشی افقی (ارتفاع <۵۲۰px) چیدمان فشرده.
- پیش‌نیاز: مرورگر مدرن با Canvas 2D. **هیچ درخواست خارجی وجود ندارد** — فونت وزیرمتن (زیرمجموعه‌ی فارسی/لاتین، OFL) به‌صورت WOFF2 داخل خود فایل جاسازی شده.

## کنترل‌ها

| ورودی | عملکرد |
|---|---|
| ضربه روی شهر | کاشت نود لبه (اگر اسلات باز باشد) |
| نگه‌داشتن روی نود (~۱۷۰ms، داخل موج ~۲۵۰ms) یا درگ عمدی (>۱۸px) روی خود گنبد | برداشتن نود برای جابه‌جایی؛ رها کردن فقط روی شهر خالیِ هایلایت‌شده می‌نشیند، وگرنه نود سر جای خودش برمی‌گردد |
| ضربه روی نود و سپس ضربه روی شهر خالی | جابه‌جایی انتخابی (کَشِ آن شهر **ریست** می‌شود!) |
| سوایپ روی ربات‌ها | نابودی موج DDoS (شعاع مؤثر ~۲۴px حول خط سوایپ) |

| `M` صدا · `R` شروع مجدد روی صفحه‌ی باخت | |

هشدار: سوایپ روی شهرها در جریان موج، «آتش خودی» است: ‎−۳ رضایت و ریست کمبو.

## مکانیک‌های اصلی

- **۱۵ شهر ایران**؛ هر درخواست به نزدیک‌ترین نودِ آنلاین می‌رود؛ هیتِ کَش سریع است وگرنه fetch از **سرور مبدأ** (خیلی دور) انجام می‌شود.
- **گرمای کَش:** هر هیت گرما و احتمال هیت بعدی را زیاد می‌کند؛ نودِ بی‌کار سرد می‌شود؛ جابه‌جایی/قطعی کَش را می‌شوید.
- **SLA / رضایت:** تایم‌اوت ‎−۸، نشت ربات ‎−۶، آتش خودی ‎−۳؛ صفر = باخت. سروِ سریع رضایت می‌افزاید.
- **امتیاز × کمبو:** سرو سریع پشت‌سرهم کمبو می‌سازد (سقف ×۳)؛ تایم‌اوت کمبو را می‌شکند. رشد امتیاز بعد از ۱۲۰ ثانیه مهار می‌شود (ضریب تا ۰٫۵) تا واریانس محدود بماند.
- **رویدادها:** 🍉 شب یلدا (ترافیک جهانی ×۱٫۸)، 🛒 بلک‌فرایدی (یک شهر ×۶ + درخواست سنگین)، 🔥 وایرال (یک شهر ×۱۰)، 🔌 قطعی برق (یک نود ۶ ثانیه آفلاین).
- **موج‌های DDoS:** ربات‌ها از مرزها به سمت نودها می‌آیند؛ سوایپ = شلیک. هر ۳ موج یک موج بزرگ (باس). موج بی‌نقص = ‎+۳۰۰ امتیاز و ‎+۵ رضایت.
- **آموزش:** زیرنویس‌های راهنما (هر کدام ≥۲٫۵ ثانیه می‌مانند و پس از ~۵ ثانیه خودکار پنهان می‌شوند)؛ با پاک‌کردن اولین موج یا رسیدن به ۷۰ ثانیه تمام می‌شود و دیگر تکرار نمی‌شود. در ۲۵ ثانیه‌ی اول شروع کند و کف رضایت ۷۰ است.
- **چالش روزانه:** سید قطعی از تاریخ تهران؛ کارت اشتراک ۱۰۸۰×۱۳۵۰ با fallback کپی/دانلود.

## تست‌ها

یک فرمان برای همه‌ی تست‌های هدلس (خروجی غیرصفر هنگام شکست):

```bash
node tests/run_all.js
```

شامل: determinism، اینواریانت reroute پس از move/outage/attack، دودِ حلقه‌ی منو (startRun→toMenu→۳۰۰ فریم)، کامل‌شدن آموزش، برچسب قفل سینی، هندسه‌ی حلقه‌ی گرما (ctx ضبط‌کننده)، شعاع سوایپ پیکسلی، باندهای سختی (lazy/novice/human/expert/greedy) و soak پنجاه سیدی.

تست بصری (اختیاری، نیازمند Playwright):

```bash
pip install playwright && python -m playwright install chromium
python3 tests/visual_qa.py            # اسکرین‌شات‌ها در tests/screenshots
```

ماتریس ۶ viewport × ۵ صفحه + کارت اشتراک؛ متریک‌های چاپ‌شده: عرض نقشه ≥۲۸۰px در ۳۲۰×۵۶۸ و ارتفاع ≥۳۰۰px در ۸۴۴×۳۹۰ (در آخرین اجرا: ۲۸۰×۲۵۰ و ۳۹۲×۳۵۰). نمونه اسکرین‌شات‌ها در `tests/screenshots/` کامیت شده‌اند.

## ساختار فایل

`index.html` تک‌فایل با بخش‌های: `CONFIG · UTIL · DATA · STORAGE · SIM · INPUT · RENDER · AUDIO · UI · SHARE · DEMO · MAIN`

- **SIM:** timestep ثابت `DT=1/60` با accumulator (سقف ۵ گام) ⇒ قطعی؛ رویدادهای تایپ‌شده برای render/audio/UI.
- **RENDER:** لایه‌ی استاتیک کش می‌شود؛ DOM HUD فقط هنگام تغییر مقدار به‌روز می‌شود؛ اسپارک‌لاین یک‌بار در ثانیه؛ لیست pending هر شهر یک‌بار در فریم.
- **AUDIO:** WebAudio با گام شور؛ بدون فایل صوتی.
- **STORAGE:** `localStorage` کلید `cmiyc.v1` داخل try/catch.
