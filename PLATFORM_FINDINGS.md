# Platform discovery — no account access yet

Research only, **UNVERIFIED ON ARVAN** unless explicitly marked otherwise. No production deployment or account access took place.

* The official [CLI installation guide](https://docs.arvancloud.ir/en/developer-tools/cli/install/) specifies an Arvan apt repository and `apt install arvan`, among other OS methods. In this sandbox a direct HTTPS request to its signing-key URL timed out after 20 seconds; `arvan` was not present. We did not install an unverifiable binary.
* The official [authentication guide](https://docs.arvancloud.ir/fa/developer-tools/cli/authentication/) states `arvan auth login` requests a **machine-user access key**, not an account password; it says the key is saved through the OS credential manager. No key was provided or created and no login attempted. The older `r1ec` npm package also failed with ENOVERSIONS in the earlier session.
* [Dashboard docs](https://docs.arvancloud.ir/fa/edge-computing/dashboard/) describe uploading a built file and testing the default URL; [route docs](https://docs.arvancloud.ir/fa/edge-computing/trigger/path/) say an `arvanedge.ir` subdomain is allocated by default. This does not verify this particular bundle on the service.
* [Object Storage](https://docs.arvancloud.ir/en/developer-tools/sdk/object-storage/credentials/) is S3-compatible and requires an access key, secret and endpoint. Whether Edge `fetch` + WebCrypto/SigV4 works, consistency/atomicity and account availability have **not** been tested. No store provisioned or keys requested. A raw-TCP database connection from this runtime has not been tested; do not assume it works.
* [AI gateway documentation](https://docs.arvancloud.ir/fa/aiaas/gateway/) describes `/v1/chat/completions`, `Authorization: apikey …`, a machine-user key, and token-based charges. Account/model access and limits are unknown. No calls were made; AI functionality is **not implemented**, not even template-only yet.
* Runtime CPU, bundle/body limits, capabilities, headers, timezone data, cold/warm latency, secrets bindings and live behavior remain **UNVERIFIED ON ARVAN**. No probe was deployed. An Edge environment-variable management endpoint appears in the [Edge API spec](https://www.arvancloud.ir/api-docs/ec-1.0.yaml), but runtime access semantics are unverified.
